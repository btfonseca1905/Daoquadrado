# Daoquadrado — 38 skills para Claude Code

## Instalação (alunos)

No Claude Code (terminal ou extensão do VS Code), cole estes dois comandos:

```
/plugin marketplace add btfonseca1905/Daoquadrado
/plugin install dq@daoquadrado
```

Depois rode `/reload-plugins` (ou reabra o Claude Code). As skills ficam disponíveis com o prefixo `dq:`.

**Alternativa sem comandos:** clone este repositório, abra a pasta no VS Code com o Claude Code e confie na pasta. O plugin é oferecido automaticamente.
