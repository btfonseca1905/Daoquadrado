# Daoquadrado — marketplace de skills para Claude Code

Instalação (no Claude Code, inclusive na extensão do VS Code):

```
/plugin marketplace add btfonseca1905/Daoquadrado
/plugin install delivery-workflow@daoquadrado
/plugin install afpm@daoquadrado
/plugin install afpb@daoquadrado
```

| Plugin | Conteúdo |
|---|---|
| delivery-workflow | `/story`, `/spec`, `/plan`, `/execute`, `/bug` |
| afpm | skills AI-First Product Manager |
| afpb | skills AI-First Product Builder |

Após instalar, as skills aparecem com o prefixo do plugin (ex.: `/delivery-workflow:story`).
Veja `ATTRIBUTION.md` para a origem e a licença das skills AI-First.
